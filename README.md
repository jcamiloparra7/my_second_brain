# My Second Brain

A Git-backed knowledge base for concepts, ideas, projects, and daily notes.

## Structure

- `concepts/` — atomic concept notes
- `areas/` — long-term areas of responsibility or interest
- `projects/` — active initiatives with linked notes
- `daily/` — daily notes and journal entries
- `docs/` — repository guides and workflows
- `templates/` — reusable note templates
- `assets/` — images and other attachments

## Conventions

- Write notes in Markdown.
- Use `[[wikilinks]]` to connect ideas.
- Prefer one concept per file using kebab-case filenames.

## Getting started

Create a new concept from `templates/concept-template.md`, save it under `concepts/`, and link it to related notes.

See `docs/copilot-usage.md` for prompts and workflows to use Copilot for note creation and linking.
