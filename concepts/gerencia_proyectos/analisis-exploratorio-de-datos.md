# Analisis exploratorio de datos

## Idea principal

El analisis exploratorio de datos (EDA) permite entender estructura, distribuciones, relaciones y variabilidad de las variables antes de modelar.

## Objetivos

- describir la muestra con rigor estadistico basico
- contrastar supuestos iniciales del problema de negocio
- detectar patrones, diferencias entre grupos y posibles anomalas
- validar si ciertas tecnicas analiticas son viables

## Metodos graficos frecuentes

- tablas de frecuencia
- graficos de barras
- graficos de torta
- tallo y hoja
- histogramas
- diagramas de caja
- graficos de tendencia temporal

## Metodos numericos frecuentes

- tendencia central: media, mediana, moda
- dispersion: varianza, rango, MAD
- forma: asimetria y curtosis
- asociacion: correlacion entre variables (-1 a 1)

## Valor para el proyecto

EDA reduce incertidumbre: puede confirmar el planteamiento inicial o mostrar que el problema requiere reformulacion antes de construir modelos.
