# Accesibilidad de Datos

Para un proyecto de Analytics, es muy importante conocer y planificar el acceso a los datos desde etapas tempranas.

## Aspectos Clave de Accesibilidad

### 1. Identificación de Datos Disponibles
Reconoce qué información puedes acceder:
- Datos internos de la organización
- Bases de datos públicas externas
- Sistemas de terceros

### 2. Procedimientos de Acceso
Establece cómo obtener datos:
- Acceso directo a sistemas
- Solicitudes formales a áreas internas
- APIs externas
- Procesos de extracción

### 3. Naturaleza de los Datos
Comprende características de disponibilidad:
- **¿Información pública o privada?**
- **¿Cuándo se puede obtener?** (disponibilidad temporal)
- **¿Mediciones continuas o puntuales?**
- **¿Frecuencia de actualización?**

### 4. Consideraciones Legales y de Confidencialidad
Procesos críticos que deben iniciarse temprano:
- **Acuerdos de confidencialidad** (NDA)
- **Solicitudes formales de información**
- **Cumplimiento regulatorio** (GDPR, leyes locales)
- **Derechos de uso de datos**

> Iniciar estos procesos temprano es esencial para evitar retrasos y dificultades en ejecución del proyecto.

## Cuándo Planificar Accesibilidad

La accesibilidad debe considerarse durante:
- Definición de necesidades de datos
- Planificación de objetivos del proyecto
- Evaluación de viabilidad técnica
- Estimación de cronograma

Una limitación en acceso puede requiere:
- Cambiar especificaciones de datos
- Ajustar objetivos del proyecto
- Modificar metodología
- Extender cronograma
